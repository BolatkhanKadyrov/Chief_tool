# PRD: Анализ технологических карт

_Последнее обновление: 2026-10-03. Текущий этап: 5 из 5._

## Цель
Из технологических карт собрать общую базу ингредиентов и для каждого блюда показать, какая доля его ингредиентов используется в других блюдах. Видно ингредиенты, которые закупаются ради одного блюда.

## Пользователь
Шеф-повар. Знает программирование немного, хочет уметь читать и править код. Работает на своём компьютере, без интернета и регистрации.

## Функции MVP
- [x] Добавление, редактирование, удаление блюда через форму (название + ингредиенты).
- [x] Добавление и редактирование вставкой текста (один ингредиент на строку). Вкладки «Форма» / «Вставить текстом» переносят введённое друг в друга.
- [x] Автоматическая база ингредиентов из всех блюд (вычисляется).
- [x] Нормализация названий: нижний регистр, лишние пробелы убраны. Синонимы вне MVP.
- [x] Для каждого блюда: процент общих ингредиентов и список уникальных.
- [x] Мгновенный пересчёт при добавлении, изменении, удалении блюда.
- [x] Список ингредиентов с числом блюд и списком блюд, сортировка по названию и числу блюд, фильтр «одиночки».
- [x] Кнопка «Загрузить пример» (4 блюда проверочного набора) при пустой базе.
- [x] Хранение в localStorage.
- [x] Экспорт/импорт JSON (кнопки в шапке; файл `techcards-ГГГГ-ММ-ДД.json`). При импорте в непустую базу — окно «Заменить всё / Объединить / Отмена». Неверный файл не меняет данные.
- [x] Экспорт/импорт Excel (.xlsx), библиотека SheetJS 0.18.5 лежит рядом (`xlsx.full.min.js`). Импорт читает лист «Блюда» (или первый лист), пропускает заголовок и пустые строки; тот же диалог «Заменить / Объединить».

## Формула
Для блюда D: I(D) — множество его ингредиентов после нормализации (повторы внутри блюда считаются один раз).
- Общий ингредиент: есть хотя бы в одном другом блюде (в базе встречается в ≥ 2 блюдах).
- Уникальный ингредиент: есть только в этом блюде.
- **процент = |общие| / |I(D)| × 100**, в интерфейсе округляется до целого.
- Блюдо без ингредиентов: «—» (деления на ноль нет).
- Единственное блюдо в базе: 0% с пометкой «в базе одно блюдо».

## Формат данных
Блюдо: `{ id, name, ingredients: [строки] }`. Хранение: `localStorage["techcards_v1"] = {"version":1,"dishes":[...]}`.
JSON-резервная копия имеет тот же вид.

## Формат Excel (этап 4)
- Лист «Блюда»: заголовки «Блюдо» | «Ингредиент», по строке на пару. Это же формат импорта.
- Лист «Оценка»: «Блюдо» | «Процент» | «Уникальные ингредиенты».
- Лист «Ингредиенты»: «Ингредиент» | «Число блюд».
- Блюдо без ингредиентов: строка с пустой ячейкой ингредиента.

## Импорт при непустой базе
Диалог: заменить всё / объединить / отмена. При объединении блюдо с тем же названием (после нормализации) заменяется.

## Ограничения
- Один файл `index.html` (HTML + CSS + JS), открывается двойным кликом, без сервера и сборки.
- Без фреймворков. Внешняя библиотека — только SheetJS для Excel (лежит рядом файлом `xlsx.full.min.js`).
- Интерфейс и комментарии в коде на русском. Код простой.
- Структура не мешает загрузке в git и бесплатному хостингу.

## Вне MVP
Граммовки и стоимость, объединение синонимов, учётные записи.

4. Excel экспорт/импорт. **(готово)**
