# Анализ технологических карт

Инструмент для шеф-повара: по списку блюд показывает, какая доля ингредиентов каждого блюда используется в других блюдах, и какие ингредиенты закупаются только ради одного блюда.

## Как открыть
Двойной клик по `index.html`. Сервер, установка и интернет не нужны. Данные хранятся в браузере (localStorage); для резервной копии есть экспорт и импорт JSON и Excel.

## Файлы
- `index.html` — всё приложение (HTML + CSS + JS, комментарии на русском).
- `xlsx.full.min.js` — библиотека SheetJS 0.18.5 для Excel. Должна лежать рядом с `index.html`.
- `PRD.md` — требования к продукту.

## Как выложить в интернет (бесплатно)
Приложение — статический сайт, подойдёт любой статический хостинг. Выкладывайте папку целиком (оба файла).
- **GitHub Pages:** загрузить проект в репозиторий GitHub → Settings → Pages → Branch `main`, папка `/ (root)`.
- **Netlify** или **Cloudflare Pages:** подключить репозиторий или перетащить папку проекта в окно загрузки.

Важно: данные хранятся в браузере каждого пользователя на конкретном адресе. Они не переезжают между устройствами сами — для переноса используйте экспорт и импорт.
